## 🛡️ Current Projects

### [Python Intrusion Detection System](https://github.com/ZeroDavo/python-ids)
A signature-based IDS built from scratch in Python using Scapy. Monitors live network traffic in real time and detects nine categories of attack behavior across five OSI layers.

- 9 detection rules — port scans, SYN floods, brute force, ARP spoofing, DNS exfiltration, cleartext credentials, and more
- Tested against real attack tools — Nmap, hping3, Hydra, arpspoof
- Integrated with **Wazuh SIEM** — alerts flow from IDS → agent → dashboard in real time
- MITRE ATT&CK auto-mapped in the Wazuh dashboard
- Built and verified in an isolated 3-VM VirtualBox lab
